# Agent Guidelines for rakuen-live

## Rule: Text Preservation
- **Do NOT revert, roll back, or undo** any changes the user has made to text content, including but not limited to:
  - Blog post files (`blog/posts/*.md`)
  - Novel files or chapters (`folios/**/*.md`)
  - Summaries, descriptions, titles, comments, or copywriting inside HTML/JS templates.
- **Intentional User Changes**: Any modifications to written text are considered intentional. Ensure that your edits only adjust code logic, structures, and CSS styles without reverting user modifications to the copy.
